# X 屏蔽模式

一个用于 X / Twitter 的 Chrome 扩展，可以在网页中快速选择账号，并批量执行屏蔽或静音操作。

## 功能

- 在 `x.com` 和 `twitter.com` 页面显示悬浮工具栏
- 点击悬浮图标进入选择模式
- 支持点击帖子选择账号
- 支持选择当前屏幕账号
- 支持批量导入账号、主页链接或用户名
- 支持后台自动执行屏蔽 / 静音队列
- 执行前可以检查和移除已选账号
- 本地保存屏蔽和静音历史
- 历史记录支持点击账号打开主页
- 支持中文和英文界面

## 本地开发

```bash
npm install
npm run build
```

构建完成后，在 Chrome 扩展管理页中加载 `dist` 文件夹：

1. 打开 `chrome://extensions/`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择项目里的 `dist` 文件夹

## 使用说明

1. 打开任意 X 页面
2. 点击页面右侧的悬浮图标
3. 选择需要处理的账号
4. 点击“屏蔽”或“静音”
5. 检查列表后确认执行

如果需要批量处理账号，可以点击“导入”，粘贴如下格式：

```text
@jack
x.com/elonmusk
username_123
```

## 隐私说明

历史记录和队列状态保存在浏览器本地存储中。扩展不会上传这些数据到第三方服务器。
