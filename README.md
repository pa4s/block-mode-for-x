# Block Mode for X

A Chrome extension for selecting X accounts on the page and running batch block or mute actions with a floating toolbar.

## Features

- One-click floating toolbar on `x.com` and `twitter.com`
- Select accounts from visible posts or import handles in bulk
- Run block and mute queues in the background
- Review selected accounts before processing
- Local history for completed block and mute runs
- Chinese and English UI

## Development

```bash
npm install
npm run build
```

Load the generated `dist` folder as an unpacked Chrome extension.
